# 🥢Игра "Палочки"

Увлекательная настольная игра, реализованная на **Python** с использованием графической библиотеки **Tkinter**. Игра представляет собой цифровую версию классической игры, в которой игрокам необходимо соединять точки на поле, чтобы закрывать квадраты и набирать очки.

---

## 🎮 Правила игры

1. **Цель**: Закрыть как можно больше квадратов на игровом поле.
2. **Ход**: Игроки по очереди соединяют две соседние точки горизонтальной или вертикальной линией.
3. **Очки**: Игрок, который замыкает четвертую сторону квадрата, получает 1 очко и право на дополнительный ход.
4. **Финал**: Игра заканчивается, когда все возможные линии на поле заполнены. Побеждает тот, кто закрыл больше квадратов.

---

## 🚀 Запуск

1. Убедитесь, что у вас установлен **Python 3.14**.
2. Скачайте исходные файлы в формате **ZIP-архива**.
3. Запустите файл **main.py** в **PyCharm**.

---

## 🧠 Рекомендации по освоению игры

1. **Для новичков**: Начните с режима «Игра с Ботом» на **Простом уровне сложности**. Это позволит вам привыкнуть к управлению, понять принцип соединения линий и начисления очков без лишнего давления.
2. **Изучение стратегии**: Перейдите на **средний уровень сложности**. Старайтесь не создавать линии, которые позволят боту замкнуть квадрат следующим же ходом.
3. **Мастерство (цепочки)**: Для глубокого изучения механики игры переключайтесь на **сложный уровень сложности**. Здесь бот будет активно выстраивать цепочки из квадратов. 
   - *Совет*: Старайтесь создавать «жертвенные» линии, чтобы заставить противника открыть вам путь к закрытию сразу нескольких квадратов («цепочке»).
4. **Тактическая хитрость**: Помните, что в игре «Палочки» иногда выгоднее отдать один квадрат противнику, чтобы получить доступ к выгодной позиции в другой части поля. Учитесь «считать» ходы наперед!
